DICOM Integration (Pentax EPK-i8020c)
Enable DICOM Integration
Allows the EPK-i8020c to push images directly to this application, serve the patient worklist to the processor, and receive procedure start/end signals.
Restart the application after changing this setting.
AE Title
This application's DICOM AE Title (max 16 chars). Must match the PACS AE Title configured on the EPK-i8020c.
PACS Port
Port for receiving scope images (C-STORE).
MWL Port
Port for worklist queries (C-FIND).
MPPS Port
Port for procedure status (N-CREATE/N-SET).
EPK-i8020c Network Setup: On the processor go to Settings → Network → DICOM and set:
PACS IP = this PC's IP  |  PACS Port = PACS Port above  |  PACS AE Title = AE Title above
MWL IP = this PC's IP  |  MWL Port = MWL Port above
MPPS IP = this PC's IP  |  MPPS Port = MPPS Port above
